
# icqr-mock
this is a repo try to recreate the icqr tree using threejs

## flow
1. form the qr code
2. get the qr matrix/list
3. generate the visual base on it

## interaction
- left mouse rotate
- right mouse pan
- middle mouse zoom

## run
- `python -m http.server `

## reference
- https://tree.icqr.com/
